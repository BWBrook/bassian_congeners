# AGENTS.md for Bassian Congeners

## Purpose

This repository supports a comparative, camera-first study of repeated
congeneric partitioning in Brush/Common Bronzewings and Black/Grey Currawongs.
Tasmania and the private camera network are the primary empirical core.

## Before work

- Read this contract and the active goal packet before taking action.
- Keep each assignment within its stated read, write, data-access, and publish
  boundaries.
- Treat the three concept notes in docs/ as source material, not as empirical
  results.
- Do not inspect any private or public dataset unless a later goal names the
  source, access method, permitted operations, and expected outputs.
- Escalate missing authority or a material conflict rather than widening scope.

## Private data

- Default to no access. A file path, mounted volume, database, image store, or
  credential is not permission to inspect it.
- Never place credentials, access tokens, raw images, exact sensitive
  coordinates, or private-data extracts in Git.
- Do not copy, transform, derive, export, or retain private data unless the
  active goal explicitly permits each operation.
- Keep data custodianship, licensing, coordinate privacy, and output-release
  rules explicit. Use de-identified summaries only when authorised.
- Preserve source identifiers and provenance in analysis work, but do not
  expose them beyond the approved boundary.

## Scientific claims

- Separate observation, Barry-provided context, and inference in every report.
- Label hypotheses and field impressions as provisional until tested.
- State material uncertainty, missingness, exclusions, and sensitivity limits.
- Preserve the two-pair, scale-explicit, temporally explicit scientific
  question. Do not collapse the project into four independent SDMs or a
  generic wet/dry habitat comparison.
- Do not infer competition, hybridisation, abundance, or causal mechanism from
  co-occurrence or camera detections alone.
- Keep public mainland/Bassian comparisons secondary unless a later decision
  changes scope.

## Decisions and escalation

Record durable, supported decisions in docs/decisions.md. Ask Barry before
making choices that materially affect species identity, inclusion/exclusion,
spatial or temporal units, effort definitions, coordinate handling, label
confidence, claim strength, data release, or the camera-first Tasmania-first
scope.

## Git and completion

- Preserve pre-existing worktree changes.
- Do not use destructive Git actions, including reset, clean, checkout-based
  reversion, or history rewriting.
- Do not stage, commit, push, publish, or open a pull request unless the active
  assignment explicitly authorises it.
- Change only authorised paths and report the exact footprint.
- Validate substantive outputs with raw command evidence. A completion summary
  must include files changed, checks run, uncertainty, and final Git status.
