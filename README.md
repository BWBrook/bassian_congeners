# Bassian Congeners

## Purpose

This project asks whether two unrelated congeneric bird pairs repeatedly
partition Tasmanian landscapes along a shared ecosystem-structure axis, and
whether their overlap dynamics differ. The focal comparisons are Brush versus
Common Bronzewings and Black versus Grey Currawongs.

The scientific centre is comparative and camera-first. Tasmania and the
private camera network provide the primary empirical core. The project is not
four independent species-distribution models and is not a generic wet/dry
habitat study.

## Current status

The repository is at concept stage. Its notes contain project rationale,
field-informed hypotheses, and an initial novelty assessment; they do not
contain results from a camera-data audit. Goal 001 establishes the repo-local
operating foundation and a questionnaire for a later, separately authorised
data audit. No real dataset has been inspected for Goal 001.
